# Gia

Autonomous AI agent built on LangGraph, achieving 75% on the GAIA benchmark

## Details

Architected a ReAct-loop agent using LangGraph with Claude Sonnet 4.6 as the core reasoning model.
Integrated 10+ tools spanning web search/extraction, Wikipedia lookup, code execution, image analysis, audio transcription, and document parsing (PDF, spreadsheet, DOCX, YouTube transcripts)
Scored 75% on the GAIA benchmark.
